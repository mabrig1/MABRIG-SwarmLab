About MABRIG SwarmLab

SwarmLab demonstrates 20–50 coordinated specialist agents in four dependency-aware waves. The default mode is a transparent, scripted simulation. A Cloudflare Worker can securely call a real language model for each agent when configured.

No AI calls happen in simulation mode. The live gateway never puts the OpenRouter API key in browser code. Review all outputs; agents cannot publish, purchase, or change accounts.
